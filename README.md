# 施工鷹架分析設計

互動式施工鷹架構件試算，支援即時檢核、風力分析及原生 Word 計算書匯出。

## 使用

直接開啟 index.html，或由 GitHub Pages 開啟。所有程式及 Word 套件均為本地檔案。

GitHub Pages 設定：Deploy from a branch → main → / (root)。

## 功能

- 可收合參數區與即時構件使用比。
- 立柱、壁連桿、托架與錨栓個別檢核。
- 詳細公式、數值代入與 Word 匯出。

## 適用範圍

本工具為構件試算，非完整施工架結構設計。工程假設、規範版本、未涵蓋項目及產品容量需求請詳閱網頁和匯出計算書。
